# Analisis Komparatif Platform

| Aspek               | Web                                                                      | Desktop                                                                              | Mobile                                                                       |
| :------------------ | :----------------------------------------------------------------------- | :----------------------------------------------------------------------------------- | :--------------------------------------------------------------------------- |
| **Bahasa utama**    | HTML, CSS, JavaScript (serta PHP, Python, dsb. untuk backend)            | C++, C#, Java, Python                                                                | Kotlin, Java (Android), Swift (iOS), Dart, React Native                      |
| **Arsitektur**      | Client-Server (berjalan di atas browser)                                 | Standalone (Monolithic) atau Client-Server                                           | Client-Server atau Standalone dengan integrasi API/Sensor                    |
| **Cara distribusi** | URL / Hosting / Cloud                                                    | File Installer (.exe, .dmg), Microsoft Store                                         | Google Play Store, Apple App Store                                           |
| **Keunggulan**      | _Cross-platform_, tidak perlu instalasi khusus, pembaruan instan.        | Akses langsung ke perangkat keras keras, performa tinggi, bisa berjalan _offline_.   | Portabilitas tinggi, integrasi sensor (GPS, kamera), notifikasi _real-time_. |
| **Keterbatasan**    | Sangat bergantung pada koneksi internet, akses perangkat keras terbatas. | Harus dikembangkan spesifik untuk OS tertentu (Windows/Mac/Linux), instalasi manual. | Kapasitas baterai dan memori terbatas, ukuran layar kecil.                   |
| **Contoh aplikasi** | WhatsApp Web, Figma Web, Google Docs                                     | Visual Studio Code, Microsoft Word, Adobe Premiere Pro                               | WhatsApp, Instagram, Gojek                                                   |

**Refleksi:**

**Platform mana yang paling menarik untuk dipelajari? Mengapa?**

_Platform yang paling menarik untuk saya pelajari adalah Web, khususnya pengembangan Full-Stack dan Progressive Web Apps (PWA). Ketertarikan ini muncul karena platform Web menawarkan fleksibilitas cross-platform yang luar biasa; satu aplikasi dapat diakses dari berbagai sistem operasi tanpa mengharuskan pengguna melakukan instalasi yang rumit. Selain itu, ekosistem Web berkembang sangat pesat dengan hadirnya framework modern seperti React, Next.js, dan Tailwind CSS yang memungkinkan pembuatan antarmuka responsif dan estetis._

**Apa tantangan terbesar saat setup environment?**

_Tantangan terbesar saat melakukan setup environment adalah mengonfigurasi path untuk Java JDK agar dapat dikenali dengan baik oleh sistem dan terhubung dengan Android Studio, serta mengelola ukuran file Android Studio dan SDK-nya yang memakan ruang penyimpanan cukup besar di perangkat._

**Bagaimana rencana Anda mengatasi tantangan tersebut?**

_Rencana saya untuk mengatasi tantangan tersebut adalah dengan selalu membaca dokumentasi resmi terkait instalasi secara teliti, serta memastikan untuk menghapus file cache atau komponen tools versi lama yang sudah tidak digunakan agar ruang penyimpanan tetap optimal. Saya juga akan lebih aktif berlatih menggunakan command line interface (CLI) agar terbiasa menangani error path di kemudian hari._
